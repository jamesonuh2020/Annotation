# Annotation

A project for performing functional annotation on gene expression data.

## Features
- Functional annotation processing (`functional_annotation.py` / `annotation_script.py`)
- Notebook workflows for analysis (`functional_annotation.ipynb` & `annotation.ipynb`)
- Analyzed differential gene expression output (`annotated_top_degs.csv`, `upregulated_genes.csv`)

## Requirements
- Python 3.x
- Notebook

## Usage
Run the script to perform annotation on your data:
python functional_annotation.py
